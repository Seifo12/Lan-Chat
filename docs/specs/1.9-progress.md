## Open questions carried into implementation

- Pre-send hashing cost for a 2 GB file on a phone.
- Whether holding sockets outside the 25-slot semaphore changes the
  connection-admission maths under a 25-peer fan-out.
- Whether `ADMISSION_POOL_SLOTS = 8` is right, or the pool should be unbounded
  because a hold is a suspension rather than a thread.
- `[unverified]` Whether Nearby can cancel an incoming payload before any
  bytes are written. Read the official documentation first; if it cannot, the
  spec requires the mesh consent path to be documented as hold-or-discard
  rather than promising a guarantee it cannot keep.
- Whether the mesh inline photo and voice paths, which write raw bytes with no
  at-rest encryption today, are aligned in task 9 or deferred with a recorded
  reason.
